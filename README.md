# Squarelight

Squarelight is a 2-player browser board game about claiming squares on a grid of points.

Open `index.html` in a browser, or serve the folder locally:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Then visit `http://127.0.0.1:4173/index.html`.

The full app prompt/spec is saved in `PROMPT.md`.
